# 🧮 Basic Calculator

Простой консольный калькулятор на Python.

## 📌 Возможности

Калькулятор поддерживает четыре основные математические операции:

- ➕ Сложение
- ➖ Вычитание
- ✖️ Умножение
- ➗ Деление

Также предусмотрена проверка деления на ноль и обработка неправильного ввода.

## 🛠️ Технологии

- Python 3
